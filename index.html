Features

書く・鳴らす・見る を一つの画面で

エディタ AvalonEdit

  • MML の構文ハイライトとレインボー括弧
  • #macro の補完とホバー表示
  • コンパイルエラー行を保存前にライブ表示
  • タブで複数ファイル、上下分割表示

コンパイル & 再生 mgsc / libkss

  • Ctrl+Enter でコンパイルしてすぐ再生
  • テンポを半分にするスロー再生
  • カーソル行から再生
  • 波形スクラバーでシーク、リピート再生

可視化 FMDSP

  • 再生中の音符をエディタ上でハイライト
  • ピアノロールとトラックロールバー
  • 音量変化を重ねるベロシティレーン
  • チャンネルごとの仮想キーボード、クリックでミュート / ソロ
  • グラフィックイコライザ、レベルメーター

ファイル管理

  • フォルダのファイルツリーと、#title 表示
  • 複数曲をまとめて流すプレイリスト
  • MGS → MML のデコンパイル
  • MGSC MML マニュアルをアプリ内ヘルプで表示

見た目と作業環境

  • レイアウトと開いていたファイルを次回に復元
  • 新規ファイルのテンプレートを設定で変更

About this beta

ベータ版について

普段使いできる状態ですが、まだ手を入れている途中です。気づいたことがあれば教えてください。

WINDOWS ONLY

WPF アプリのため Windows 専用です。

TRACE

ハイライトは曲のループ 2 周分を想定して調整しています。3 周目以降や、一部の複雑な曲では音とずれることがあります。

FEEDBACK

ずれる曲を見つけたら、MML ファイルとずれる行を添えて報告してもらえると、原因を調べやすくなります。
